# Basic HTML Course - Index

This course presents the HTML material for the web development skilling program at Makerere High School Migadde.

## How to study

1. Read the chapters **in order**, because each chapter builds on the previous one.
2. **Type out** every example in a file called `index.html` and open that file in a browser.
3. Chapters marked **reference** contain full detail, so skim them on the first pass and return to them when you need the exact syntax.
