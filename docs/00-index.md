# HTML Course

HTML describes what each part of a page is: a heading, a paragraph, a link, a table, or a form field. This track starts with the structure of a single element and ends with a complete page made from semantic sections.

You do not need any previous HTML experience. Work through the chapters in order.

[Start with Elements and Page Structure](01-basic-structure.md){ .md-button }

## Getting started

- [Elements and Page Structure](01-basic-structure.md): tags, elements, attributes, nesting, and the page skeleton.
- [Headings](02-headings.md): how to outline a page and why one `<h1>` is enough.
- [Heading Levels](03-headings-showcase.md): a quick reference for `<h1>` to `<h6>` with practice.

## Text

- [Paragraphs](04-paragraphs.md): how paragraphs, line breaks, and thematic breaks differ.
- [Text Blocks](05-paragraphs-snippets.md): the exact syntax for `<p>`, `<br>`, and `<hr>`.
- [Build Your First Page](06-combined-structure.md): put headings and paragraphs together in one page.
- [Emphasis and Meaning](07-meaning-vs-looks.md): choose between `<strong>`, `<b>`, `<em>`, `<i>`, and `<mark>`.
- [Code and Technical Text](08-code-family.md): mark up code, keyboard keys, program output, and variables.
- [Small Semantic Tags](09-tiny-semantics.md): abbreviations, dates, edits, subscripts, and superscripts.
- [Quotations](10-quotes.md): inline quotes, block quotes, and citing a source.
- [Address and Fine Print](11-special-blocks.md): contact information and secondary text.

## Links, images, and lists

- [Links](12-links.md): link to pages, sections, email addresses, and other websites.
- [Images](13-images.md): image sources, alt text, dimensions, and captions.
- [Lists](14-lists.md): unordered, ordered, nested, and description lists.

## Data and input

- [Tables](15-tables.md): rows, columns, headers, captions, and data that belongs in a table.
- [Forms](16-forms-basics.md): labels, inputs, buttons, and a complete registration form.

## Page structure

- [Grouping Content](17-div-section.md): when to use `<div>`, `<section>`, and `<span>`.
- [Page Landmarks](18-landmarks.md): `<header>`, `<nav>`, `<main>`, `<footer>`, `<article>`, and `<aside>`.

## What you should be able to do at the end

- Read an HTML file and explain what each element is for.
- Build a page with a clear heading outline and correctly nested elements.
- Add links, images, lists, tables, and forms.
- Choose semantic elements instead of wrapping everything in `<div>`.
- Check your own page for missing labels, alt text, and closing tags.

The CSS track uses the same pages and adds presentation. Continue there when you can build a simple HTML page without copying the examples.
