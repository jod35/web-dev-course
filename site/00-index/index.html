Basic HTML Course - Index¶

This is course material for HTML under the web development skilling program at Makerere High School Migadde.

How to study¶

  1. Read chapters in order,each one builds on the last.
  2. Type out every example in a file called index.html and open it in a browser.
  3. Chapters marked reference are detailed,skim first, return when you need exact syntax.
